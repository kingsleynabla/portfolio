# 🔄 Design Process

My typical workflow follows:

```text
01 — Discover
      ↓
02 — Define
      ↓
03 — Design
      ↓
04 — Build
      ↓
05 — Improve
```

### 01 — Discover

Research users, understand the problem, identify constraints, and uncover opportunities.

### 02 — Define

Translate research into problem statements, user journeys, requirements, and solution criteria.

### 03 — Design

Create wireframes, prototypes, visual systems, and interaction designs.

### 04 — Build

Turn designs into responsive and functional digital products.

### 05 — Improve

Test, gather feedback, measure results, and continuously refine the experience.
